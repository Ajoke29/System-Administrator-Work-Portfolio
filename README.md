## Work Completed

### Windows 11 Workstation Setup

I was given a Dell OptiPlex desktop that had been used by another user. I was asked to reset the computer and install a fresh copy of Windows 11.

During the installation, Windows could not see the computer's internal SSD. I checked the boot settings and BIOS and worked through the issue with my supervisor.

After troubleshooting, the SSD appeared and I was able to continue the Windows installation.

I also connected the computer to the office network using Ethernet and continued with the Windows setup.

**What I worked with:**

- Windows 11
- Bootable USB
- Dell Boot Menu
- BIOS
- SSD troubleshooting
- RAID/AHCI settings
- Ethernet
- Windows setup (OOBE)
